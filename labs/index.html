CSC 227 · Introduction to JavaScript

Labs

One graded lab per lesson — three problems each, from a warm-up to a small program.

Each problem is checked in your browser as you work: press ▶ Run & check until every test is green. Your work is saved in this browser automatically. When you're done, press 📋 Copy submission, save it as submissions/<lab-id>.js in your own repository (start from the student-template), and open a pull request. Your instructor re-runs the same tests to record the grade and reviews your code on the pull request.
