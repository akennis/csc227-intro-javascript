CSC 227 · An introduction to programming in JavaScript

Introduction to JavaScript

Twenty-two notebook-style lessons that take you from your first variable to web APIs, Node.js, and React — all in the browser.

No setup required. Every lesson mixes plain-English explanations with live JavaScript you can edit and run right on the page, and inline challenges that check your code as you go. Examples that work with web pages run in a small sandboxed page shown under the code, so you can click the buttons and type into the inputs your program controls. Work through the lessons in order — each builds on the one before — then practise with that lesson's lab.

Part 1 · Foundations

From a first Git commit to variables, functions, decisions, and loops — the core of every program.

  1. Getting Started: Git, GitHub & Karel
    Version control, pull requests, and how this course's labs are submitted.
  2. Values, Types & Variables
    Strings, numbers, booleans, let and const, typeof, and scope.
  3. Functions
    Parameters, return values, pure functions, and composing small functions.
  4. The Console & the Debugger
    Run code instantly, read error messages, and step through a program.
  5. Booleans & Decisions
    Comparison and logical operators, truthiness, and if / else if / else.
  6. Loops
    while, for, nested loops, and why locals beat globals.

Part 2 · Programs in the page & data

Connect JavaScript to HTML, then organise data with strings, arrays, objects, and closures.

  1. JavaScript in the Page
    <script>, external files, reading inputs, and handling button clicks.
  2. Strings
    Combine, compare, search, slice, split, and build text with template literals.
  3. Arrays
    Ordered lists: indexing, push/pop, sorting, passing by reference, map/filter/reduce.
  4. Objects as Maps
    Key/value lookup: add, update, delete, loop over keys, and pass objects to functions.
  5. Modeling Systems with Data
    Describe a real system as objects, then evolve it with functions — a simulation.
  6. Closures: Objects with Behavior
    Constructor functions that bundle private data with the methods that use it.

Part 3 · The DOM, events & functions

Change the page from code, respond to the user, handle errors, and treat functions as data.

  1. The DOM I: From HTML to a Live Document
    How the browser turns HTML into a tree of objects; finding, reading and changing elements, attributes, classes and forms.
  2. The DOM II: Building & Navigating the Tree
    Create, insert, move, clone and remove nodes; render pages from data; walk the tree; work with the browser's rendering.
  3. Events
    addEventListener, event targets, and handling many elements at once.
  4. Multiple Returns & Errors
    Destructuring, errors as values, and exceptions with try / catch.
  5. Functions as Data, Recursion & Arrows
    Store and pass functions, solve problems recursively, and write arrow functions.

Part 4 · Talking to the world

Call web APIs, wait without freezing, remember data, and meet Node.js and React.

  1. Ajax with XMLHttpRequest
    Request data from a web API without leaving the page.
  2. Async / Await & fetch
    Promises, await, error handling, and parallel requests with Promise.all.
  3. localStorage
    Save key/value data in the browser so it survives a reload.
  4. Node.js
    JavaScript outside the browser, and a tiny web server and API.
  5. React & npm
    Components, JSX, props, and state — and how npm packages fit in.

Labs

Each lesson has a graded lab of three problems. Solve them in the browser, check them against the tests, then copy your submission into your own GitHub repository and open a pull request — exactly the workflow from lesson 1.

Playground & reference

The Playground is a blank editor with a console and a page of your own HTML. The Reference collects the syntax and built-in functions the course covers on one page.
